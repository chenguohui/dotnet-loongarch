# ============================================================================
# nupkg 上传白名单 —— nupkg.yml / scripts/nupkg-push.sh 使用
#
# 匹配对象是 nupkg 的「文件名」（即 <包 id>.<版本>.nupkg，含 .nupkg 后缀），
# 不是路径。每一行一个 glob：
#   #  开头（或行尾）  注释，空行忽略
#   !  开头            排除规则，优先级高于包含规则（命中即不上传）
#   其余               包含规则（命中即上传）
#
# 判定：先扫一遍 ! 规则 —— 命中则排除；否则再扫包含规则 —— 命中则上传；
#       两边都没命中 = 不上传（不报错，脚本会把未命中的列出来）。
#
# 注意：ABI1.0 与 ABI2.0 的包 id / 版本完全相同，靠 feed 区分
#       （ABI1.0 -> nuget.loongnix.cn，ABI2.0 -> lnuget.loongnix.cn），
#       不要试图在这份白名单里区分 ABI。
# ============================================================================

# ---- 默认规则：只上传 id 里带 loongarch64 的 RID 专有包 --------------------
# 这些就是「含 ELF、必须按 ABI 分开」的那批包（社区不生成，龙芯自维护）。
*loongarch64*.nupkg

# ---- 排除 ------------------------------------------------------------------

# 符号包（体积大，且不属于功能包）
!*.symbols.nupkg
!*.snupkg
